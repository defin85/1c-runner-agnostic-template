# EPF Source Templates

Каталог содержит копируемые source-only заготовки внешних обработок.

## Как использовать

Создайте новую обработку repo-owned командой:

```bash
./scripts/epf/init-from-template.sh --template sync-async --name МояОбработка --info "Моя обработка" --version 1.0
```

Команда копирует каталог в `src/epf/<ИмяНовойОбработки>`, переименовывает внутренний каталог и корневой XML,
заменяет шаблонное имя, пересоздает UUID и обновляет регистрационные `Информация`/`Версия`, если они переданы.

После генерации:

1. В `Ext/ObjectModule.bsl` замените тело `ВыполнитьСценарийВнутренний()` на доменную логику.
2. В `Forms/Форма/Ext/Form/Module.bsl` замените сбор параметров и применение результата к форме.
3. Проверьте форму и обработку через repo-owned validation path, который выводит команда.

## Шаблоны

- `TemplateSyncProcessor` — минимальная управляемая форма с синхронным запуском.
- `TemplateSyncAsyncProcessor` — та же форма, но запуск идет через `ДлительныеОперации` при регистрации обработки в БСП и через sync fallback при автономном открытии.

Подробное объяснение паттернов и инвариантов см. в `../AGENT_TEMPLATES.md`.
