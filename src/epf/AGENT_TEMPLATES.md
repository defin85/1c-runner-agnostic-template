# Agent Templates For External Processor Launch

Документ фиксирует два рабочих шаблона запуска внешних обработок из `src/epf`.
Перед использованием адаптируйте имена методов, структуру результата и применение результата к форме под конкретную обработку.

Если нужна не справка, а быстрый старт новой обработки, копируйте готовые source-only заготовки из `_templates`:

- `_templates/TemplateSyncProcessor` — обработка с синхронным запуском.
- `_templates/TemplateSyncAsyncProcessor` — обработка с синхронным и фоновым запуском.

## Источники паттернов

- Синхронный запуск: экспортная `...Синхронно()` из модуля объекта сразу возвращает результат, а форма применяет его на сервере.
- Синхронный запуск с адресом результата: модуль объекта кладет результат во временное хранилище, затем форма читает его через `ПолучитьИзВременногоХранилища`.
- Синхронный + асинхронный запуск: форма запускает `ДлительныеОперации.ВыполнитьВФоне` через `ДлительныеОперации.ВыполнитьПроцедуруМодуляОбъектаОбработки`, а при автономном открытии обработки откатывается к синхронному выполнению.

## Шаблон 1. Только синхронный запуск

Используйте, когда операция быстрая, должна завершаться в текущем сеансе формы и не требует фонового ожидания.

### Модуль объекта

```bsl
#Область ПрограммныйИнтерфейс

Процедура ВыполнитьСценарий(СтруктураПараметров, АдресРезультата = Неопределено) Экспорт

	Результат = ВыполнитьСценарийВнутренний(СтруктураПараметров);
	Если ЗначениеЗаполнено(АдресРезультата) Тогда
		ПоместитьВоВременноеХранилище(Результат, АдресРезультата);
	КонецЕсли;

КонецПроцедуры

Функция ВыполнитьСценарийСинхронно(СтруктураПараметров) Экспорт

	Возврат ВыполнитьСценарийВнутренний(СтруктураПараметров);

КонецФункции

#КонецОбласти

Функция ВыполнитьСценарийВнутренний(СтруктураПараметров)

	Результат = Новый Структура;
	Результат.Вставить("Успех", Ложь);
	Результат.Вставить("Сообщение", "");
	Результат.Вставить("СообщениеОбОшибке", "");

	Попытка
		ПроверитьПараметрыСценария(СтруктураПараметров);

		// Здесь выполняется доменная операция обработки.

		Результат.Успех = Истина;
		Результат.Сообщение = "Операция завершена.";
	Исключение
		Результат.СообщениеОбОшибке = ОписаниеОшибки();
	КонецПопытки;

	Возврат Результат;

КонецФункции
```

### Модуль формы

```bsl
&НаКлиенте
Процедура ВыполнитьСценарий(Команда)

	ВыполнитьСценарийНаСервере();

КонецПроцедуры

&НаСервере
Процедура ВыполнитьСценарийНаСервере()

	Обработка = РеквизитФормыВЗначение("Объект");
	Результат = Обработка.ВыполнитьСценарийСинхронно(ПолучитьПараметрыСценария());
	ПрименитьРезультатСценария(Результат);

КонецПроцедуры

&НаСервере
Функция ПолучитьПараметрыСценария()

	ПараметрыСценария = Новый Структура;
	ПараметрыСценария.Вставить("Организация", Организация);
	// Добавьте остальные значения формы. Табличные части формы передавайте через РеквизитФормыВЗначение().

	Возврат ПараметрыСценария;

КонецФункции

&НаСервере
Процедура ПрименитьРезультатСценария(Результат)

	Если Результат = Неопределено Тогда
		Возврат;
	КонецЕсли;

	Если Результат.Свойство("СообщениеОбОшибке") И НЕ ПустаяСтрока(Результат.СообщениеОбОшибке) Тогда
		Сводка = Результат.СообщениеОбОшибке;
	ИначеЕсли Результат.Свойство("Сообщение") Тогда
		Сводка = Результат.Сообщение;
	КонецЕсли;

КонецПроцедуры
```

Обязательные инварианты:

- Вся доменная логика живет в модуле объекта, форма только собирает параметры и применяет результат.
- `...Синхронно()` возвращает структуру результата напрямую.
- Экспортная процедура с `АдресРезультата` остается рядом, если позже понадобится фоновой запуск через БСП.
- `ОписаниеОшибки()` вызывается внутри `Исключение`; не выносите получение текста ошибки в отдельную функцию вне обработчика.

## Шаблон 2. Синхронный + асинхронный запуск

Используйте, когда операция может быть долгой. Шаблон запускает фон только для зарегистрированной дополнительной обработки; при автономном открытии выполняет тот же сценарий синхронно.

### Модуль объекта

```bsl
#Область ПрограммныйИнтерфейс

Процедура ВыполнитьСценарий(СтруктураПараметров, АдресРезультата) Экспорт

	Результат = ВыполнитьСценарийВнутренний(СтруктураПараметров);
	ПоместитьВоВременноеХранилище(Результат, АдресРезультата);

КонецПроцедуры

Функция ВыполнитьСценарийСинхронно(СтруктураПараметров) Экспорт

	Возврат ВыполнитьСценарийВнутренний(СтруктураПараметров);

КонецФункции

#КонецОбласти
```

Тело `ВыполнитьСценарийВнутренний()` берите из синхронного шаблона. Для прогресса внутри длинных этапов используйте защищенную обертку:

```bsl
Процедура ОтправитьПрогресс(Процент, Текст)

	Попытка
		ДлительныеОперации.СообщитьПрогресс(Процент, Текст);
	Исключение
	КонецПопытки;

КонецПроцедуры
```

### Модуль формы

```bsl
&НаКлиенте
Процедура ВыполнитьСценарий(Команда)

	ВыполнитьСценарийНаКлиенте();

КонецПроцедуры

&НаКлиенте
Процедура ВыполнитьСценарийНаКлиенте()

	ПараметрыЗапуска = ПодготовитьПараметрыЗапускаНаСервере();

	Если НЕ ФоновыйЗапускДоступенНаСервере() Тогда
		ОбщегоНазначенияКлиент.СообщитьПользователю(
			"Обработка открыта автономно. Операция будет выполнена синхронно без фонового задания.");
		ПоказатьРезультатСценария(ВыполнитьЗаданиеСинхронноНаСервере(ПараметрыЗапуска));
		Возврат;
	КонецЕсли;

	СтруктураФоновогоЗадания = ВыполнитьФоновоеЗаданиеНаСервере(ПараметрыЗапуска, УникальныйИдентификатор);

	ПараметрыОжидания = ДлительныеОперацииКлиент.ПараметрыОжидания(ЭтотОбъект);
	ПараметрыОжидания.ВыводитьОкноОжидания = Истина;
	ПараметрыОжидания.ВыводитьПрогрессВыполнения = Истина;
	ПараметрыОжидания.Интервал = 2;

	ДлительныеОперацииКлиент.ОжидатьЗавершение(
		СтруктураФоновогоЗадания,
		Новый ОписаниеОповещения("ОбработатьРезультатФоновогоСценария", ЭтотОбъект),
		ПараметрыОжидания);

КонецПроцедуры

&НаСервере
Функция ПодготовитьПараметрыЗапускаНаСервере()

	ПараметрыЗапуска = ПолучитьПараметрыСценария();
	ПараметрыЗапуска.Вставить("ИмяМетода", "ВыполнитьСценарий");

	Возврат ПараметрыЗапуска;

КонецФункции

&НаСервере
Функция ФоновыйЗапускДоступенНаСервере()

	ДополнительнаяОбработкаСсылка = Неопределено;
	Возврат Параметры.Свойство("ДополнительнаяОбработкаСсылка", ДополнительнаяОбработкаСсылка)
		И ЗначениеЗаполнено(ДополнительнаяОбработкаСсылка);

КонецФункции

&НаСервере
Функция ВыполнитьФоновоеЗаданиеНаСервере(ПараметрыЗапуска, УникальныйИдентификатор)

	ПараметрыЗадания = Новый Структура;
	ПараметрыЗадания.Вставить("ИмяОбработки", "ВнешняяОбработка.ДлительныеОперацииВоВнешнейОбработке");
	ПараметрыЗадания.Вставить("ИмяМетода", ПараметрыЗапуска.ИмяМетода);
	ПараметрыЗадания.Вставить("ПараметрыВыполнения", ПараметрыЗапуска);
	ПараметрыЗадания.Вставить("ЭтоВнешняяОбработка", Истина);
	ПараметрыЗадания.Вставить("ДополнительнаяОбработкаСсылка", ПолучитьДополнительнуюОбработкуСсылкуФормы());

	ПараметрыВыполнения = ДлительныеОперации.ПараметрыВыполненияВФоне(УникальныйИдентификатор);
	ПараметрыВыполнения.НаименованиеФоновогоЗадания = "Выполнение сценария обработки";
	ПараметрыВыполнения.ЗапуститьВФоне = Истина;
	ПараметрыВыполнения.Вставить("ИдентификаторФормы", УникальныйИдентификатор);

	Возврат ДлительныеОперации.ВыполнитьВФоне(
		"ДлительныеОперации.ВыполнитьПроцедуруМодуляОбъектаОбработки",
		ПараметрыЗадания,
		ПараметрыВыполнения);

КонецФункции

&НаСервере
Функция ВыполнитьЗаданиеСинхронноНаСервере(ПараметрыЗапуска)

	Попытка
		Обработка = РеквизитФормыВЗначение("Объект");
		Возврат Обработка.ВыполнитьСценарийСинхронно(ПараметрыЗапуска);
	Исключение
		Результат = Новый Структура;
		Результат.Вставить("Успех", Ложь);
		Результат.Вставить("СообщениеОбОшибке", ОписаниеОшибки());
		Возврат Результат;
	КонецПопытки;

КонецФункции

&НаСервере
Функция ПолучитьДополнительнуюОбработкуСсылкуФормы()

	ДополнительнаяОбработкаСсылка = Неопределено;
	Если Параметры.Свойство("ДополнительнаяОбработкаСсылка", ДополнительнаяОбработкаСсылка)
		И ЗначениеЗаполнено(ДополнительнаяОбработкаСсылка) Тогда
		Возврат ДополнительнаяОбработкаСсылка;
	КонецЕсли;

	ВызватьИсключение
		"Фоновый запуск доступен только для обработки, зарегистрированной в справочнике ДополнительныеОтчетыИОбработки.";

КонецФункции

&НаКлиенте
Процедура ОбработатьРезультатФоновогоСценария(Результат, ДополнительныеПараметры) Экспорт

	Если Результат = Неопределено Тогда
		Возврат;
	ИначеЕсли Результат.Статус = "Ошибка" Тогда
		ОбщегоНазначенияКлиент.СообщитьПользователю(Результат.ПодробноеПредставлениеОшибки);
		Возврат;
	ИначеЕсли Результат.Статус <> "Выполнено" Тогда
		Возврат;
	КонецЕсли;

	ПоказатьРезультатСценария(ОбработатьРезультатНаСервере(Результат.АдресРезультата));

КонецПроцедуры

&НаСервере
Функция ОбработатьРезультатНаСервере(АдресРезультата)

	Возврат ПолучитьИзВременногоХранилища(АдресРезультата);

КонецФункции

&НаКлиенте
Процедура ПоказатьРезультатСценария(Результат)

	Если Результат = Неопределено Тогда
		Возврат;
	КонецЕсли;

	ПрименитьРезультатСценарияНаСервере(Результат);

	Если Результат.Свойство("СообщениеОбОшибке") И НЕ ПустаяСтрока(Результат.СообщениеОбОшибке) Тогда
		ОбщегоНазначенияКлиент.СообщитьПользователю(Результат.СообщениеОбОшибке);
	ИначеЕсли Результат.Свойство("Сообщение") И НЕ ПустаяСтрока(Результат.Сообщение) Тогда
		ОбщегоНазначенияКлиент.СообщитьПользователю(Результат.Сообщение);
	КонецЕсли;

КонецПроцедуры
```

Обязательные инварианты:

- Фоновый запуск разрешен только при наличии `Параметры.ДополнительнаяОбработкаСсылка`; автономное открытие должно иметь синхронный fallback.
- Фоновый метод в модуле объекта обязан быть экспортной процедурой с параметрами `(СтруктураПараметров, АдресРезультата)` и сам помещать результат во временное хранилище.
- `ПараметрыЗапуска` должны быть сериализуемыми для фонового задания; табличные данные формы заранее конвертируйте в `ТаблицаЗначений`, `Массив` или `Структура`.
- Клиентский callback должен обрабатывать только статус `Выполнено`, а статус `Ошибка` показывать пользователю без попытки читать `АдресРезультата`.
- Для данных, которые нельзя напрямую вернуть на клиент, кладите их в отдельные адреса временного хранилища и возвращайте клиенту только безопасную структуру с адресами.

## Минимальная проверка после адаптации

1. Сравнить новый код с ближайшим рабочим примером в `src/epf`.
2. Проверить, что модуль объекта содержит обе экспортные точки: процедура для фонового запуска и функция `...Синхронно()`.
3. Проверить, что форма не выполняет доменную запись документов напрямую.
4. Запустить `form-validate` и `epf-validate` через `./scripts/skills/run-imported-skill.sh` при готовом imported-skill окружении.
5. Запустить `make agent-verify` как no-1C baseline для agent-facing изменений.
