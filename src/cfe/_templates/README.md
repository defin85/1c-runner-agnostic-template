# CFE Source Templates

Каталог содержит копируемые source-only заготовки расширений конфигурации.

## Шаблоны

- `TemplatePatchExtension` — минимальное расширение-исправление.
- `TemplateCustomizationExtension` — минимальное расширение-доработка.

Обе заготовки содержат:

- `Configuration.xml`
- `Languages/Русский.xml`
- `Roles/<Имя>_ОсновнаяРоль.xml`

Подробные правила адаптации см. в `../AGENT_TEMPLATES.md`.
