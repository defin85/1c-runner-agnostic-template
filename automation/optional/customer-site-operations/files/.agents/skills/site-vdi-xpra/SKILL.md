# Agent Skill: site-vdi-xpra

Repo script: `./scripts/site/site-operator.sh`

## Use When

- Пользователь передал файл подключения VDI и просит подключиться к площадке.
- Нужно ввести команду в удалённом терминале площадки и прочитать результат.
- Нужно перенести файл (например, обёртку из `infra/site/server/`) на сервер площадки.
- Идёт долгая удалённая операция, и сеанс не должен заблокироваться.

## Подготовка

- Прочитайте [правила площадки](../../../docs/infra/site/rules.md).
- Профиль хоста оператора — `infra/site/operator.json` (поля — в
  `infra/site/operator.example.json`): номер экрана Xpra, путь к VDI-клиенту,
  задержка ввода, параметры keepalive.

## Подключение

```bash
./scripts/site/site-operator.sh xpra-start
./scripts/site/site-operator.sh vdi-connect ~/Downloads/session.ica
./scripts/site/site-operator.sh screenshot
```

- Xpra работает без окна на хосте, без общего буфера обмена и передачи файлов.
  Окно просмотра (`view`) открывайте только по просьбе пользователя.
- Файл подключения одноразовый: использованный или удалённый клиентом файл не
  запускайте повторно, попросите свежий. Содержимое файла не выводите.
- Подключение подтверждает снимок экрана с удалённым рабочим столом.
  Снимки могут содержать данные заказчика: они остаются в приватном
  runtime-каталоге и не попадают в репозиторий.

## Ввод команды

1. Снимком проверьте: активен нужный терминал, приглашение пустое, раскладка EN.
2. `./scripts/site/site-operator.sh type --command '<команда>'` — набирает одну
   ASCII-строку без Enter.
3. Выделите набранную строку в удалённом терминале и скопируйте её, затем
   `./scripts/site/site-operator.sh verify --command '<команда>' --clipboard`.
   Либо сверьте строку по снимку и передайте её через `--observed-file`.
4. Только после `verify_match=1` — `./scripts/site/site-operator.sh enter`.
5. При `verify_match=0` очистите строку в терминале (Ctrl+U), выполните
   `clear-pending` и наберите команду заново.

Изменяющие команды набирайте только после явного разрешения пользователя.
Для частых проверок снимайте нижнюю часть терминала: `screenshot --crop WxH+X+Y`.

## Перенос файла

```bash
./scripts/site/site-operator.sh transfer infra/site/server/site-ibcmd /opt/site-ops/site-ibcmd 0755 --owner root:root --output /tmp/site-transfer.txt
```

Строки из вывода набирайте по одной через `type` → `verify` → `enter`. Файл
устанавливается только при `sha256_match=1`; при несовпадении прежний файл на
сервере не меняется.

## Долгая операция

`./scripts/site/site-operator.sh keepalive --check` проверяет, что активно окно
VDI-клиента. Без `--check` инструмент раз в заданный интервал двигает мышь
между двумя точками из профиля и завершается при смене активного окна. Он не
нажимает кнопки и клавиши. Точки выбирайте по снимку, вдали от панелей и
всплывающих окон.

## Rules

- Не управляйте одним удалённым сеансом одновременно из двух клиентов.
- Не останавливайте сервер Xpra во время удалённой операции: это обрывает сеанс.
- Не вводите пароли, PIN и токены через `type`: их вводит пользователь или
  обёртка читает их из защищённого файла на сервере.
