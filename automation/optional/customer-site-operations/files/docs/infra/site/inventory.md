# Инвентарь площадки

Шаблон для заполнения проектом. Записывайте подтверждённое live-состояние с
датой проверки; перед изменениями перепроверяйте относящиеся к ним факты.
Пароли, PIN-коды и содержимое лицензий сюда не вносите.

## Контуры

| Контур | Назначение | Доступ |
|---|---|---|
| _например, рабочий_ | _базы пользователей_ | _VDI → терминал сервера_ |
| _например, тестовый_ | _копии баз для проверок_ | _..._ |
