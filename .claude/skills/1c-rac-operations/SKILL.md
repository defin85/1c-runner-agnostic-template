# Операции с кластером 1С

Repo script: `./scripts/diag/doctor.sh`

Навык только маршрутизирует. Команды кластера выполняет обёртка `site-rac` необязательного модуля `customer-site-operations`; в шаблоне её нет, она появляется в проекте после инициализации модуля. `doctor.sh` проверяет готовность локального runtime profile и не обращается к кластеру.

## Где взять команды и сведения

- Если модуль площадки материализован, обёртка и её описание лежат в `infra/site/` и `docs/infra/site/`. Перед работой прочитайте инвентаризацию площадки и описание обёртки там.
- Если модуля нет, остановитесь и сообщите, что операции кластера в проекте не настроены. Не собирайте вызовы RAS вручную.

## Правила

- Имя базы указывайте точно. Не выбирайте первую похожую запись и не считайте копию базы исходной базой.
- Запрос проверить состояние не разрешает его менять. Явный запрос изменить конкретную базу разрешает эту операцию и проверку её результата; повторное разрешение на уже согласованное действие не запрашивайте.
- Запрет входа (`lock`/`unlock`) не завершает сеансы. Завершение чужих сеансов, перезапуск служб и изменения нескольких баз согласуйте отдельно.
- Каждая изменяющая команда должна проверить результат: нужный флаг установлен, остальные флаги базы (например, блокировка регламентных заданий) не изменились. Если нужное состояние уже установлено, изменение не выполняется.
- Раздача лицензий (`allow`/`deny`) — настройка выдачи, а не доказательство наличия или исправности лицензии.
- Пароли берутся из защищённых источников площадки. Не включайте пароли в команды, вывод и документы. Один код возврата 255 не доказывает ошибку аутентификации: не меняйте пароль или его источник только из-за него.

## Доработка обёртки

Если обёртке не хватает команды или поля для задачи, добавьте минимально необходимую возможность в обёртку модуля площадки, затем выполните задачу через обновлённую обёртку. Не закрепляйте длинные одноразовые прямые вызовы RAS как обычный способ работы и не реализуйте весь CLI заранее. Для дополнительного поля предпочитайте расширение команды `info` новой команде.

Сохраняйте точный выбор базы, закрытый вывод секретов и проверку результата изменений. Добавьте тест новой логики в существующие тесты модуля и обновите описание обёртки. Доработка обёртки не расширяет согласованный объём изменений баз.

Прямой вызов утилиты RAS допустим только для выяснения установленного контракта, диагностики или восстановления обёртки — по разделу прямых вызовов в описании обёртки площадки.
